# NUMBER ONE TRADER AI

منصة ويب عربية لتحليل الأسواق المالية وإظهار إشارات فنية تجريبية، مع بوت Telegram منفصل.

## تشغيل الموقع
1. Python 3.10 أو أحدث.
2. تثبيت المكتبات: pip install -r requirements.txt
3. تشغيل الموقع: streamlit run app.py

## تشغيل بوت Telegram
1. احتفظ برمز البوت سرًا ولا تضعه في GitHub.
2. عيّن متغير البيئة TELEGRAM_BOT_TOKEN.
3. شغّل: python telegram_bot.py
4. يحتاج البوت إلى عامل تشغيل مستمر منفصل عن تطبيق Streamlit.

البوت: https://t.me/NumberOneTraderAI_bot

## الأسواق ومصادر البيانات
- العملات الرقمية: Binance Public API.
- الفوركس والأسهم والسلع والمؤشرات: Yahoo Finance عبر yfinance.
- قد لا تتوفر جميع الأصول أو الفواصل الزمنية من المصادر المجانية.
- لا يعرض النظام سعرًا تخمينيًا عند غياب مصدر موثوق.

## الفواصل الزمنية
1m، 5m، 15m، 30m، 1h، 4h. يُعاد تكوين فاصل الأربع ساعات من بيانات الساعة عند الحاجة.

## الخصائص
- واجهة عربية داكنة مخصصة للكمبيوتر مع توافق أساسي للهواتف.
- فحص تلقائي للأسواق والأصول وتحليل أصل محدد.
- جميع الإشارات، القوية، الاتجاه، الانعكاس.
- مؤشرات EMA وRSI وMACD وBollinger Bands وStochastic وATR.
- مستويات دخول ووقف خسارة وهدف حسابية.
- سجل الإشارات وتنزيل CSV.
- محاكي تداول افتراضي وسجل الصفقات التجريبية.
- بوت Telegram بأوامر /start و/markets و/analyze و/signals و/history و/demo و/settings و/help.
- لوحة مالك أولية.

## حدود مهمة قبل الإطلاق
- هذا إصدار أولي للتحليل والتعليم والمحاكاة، وليس نظامًا مثبت الدقة أو توصية استثمارية.
- لا يوجد تنفيذ صفقات حقيقية أو ربط بوسيط أو محفظة.
- لا يوجد اختبار تاريخي للدقة أو سجل أداء مدقق بعد.
- درجة الثقة ناتجة عن توافق مؤشرات فنية وليست احتمال نجاح إحصائيًا.
- SQLite محلية؛ قد تضيع البيانات عند إعادة تشغيل الاستضافة المؤقتة. يلزم ربط قاعدة بيانات دائمة قبل الاستخدام التجاري.
- بيانات Yahoo Finance وBinance المجانية لها حدود وتغطية متفاوتة. عند غياب البيانات لا يصدر النظام إشارة.
- لا تستخدم إشارات المنصة وحدها لاتخاذ قرار مالي. التداول ينطوي على مخاطر خسارة رأس المال.

## الأسرار الاختيارية
- TELEGRAM_BOT_TOKEN لتشغيل البوت في عامل مستقل.
- OWNER_PASSWORD لحماية لوحة المالك.
- TRADER_DB_PATH لتحديد مسار قاعدة البيانات.


## ربط المساعد الذكي داخل Telegram
أضيفت محادثة عربية مباشرة عبر OpenAI Responses API:
- يرد المساعد على الرسائل النصية العادية، مع الاحتفاظ بسياق قصير منفصل لكل مستخدم.
- الأمر /reset يمسح سياق المحادثة الحالي.
- لا بد من إضافة السر `OPENAI_API_KEY` إلى بيئة تشغيل البوت، ويمكن تحديد النموذج عبر `OPENAI_MODEL` (الافتراضي `gpt-4.1-mini`).
- يظل `TELEGRAM_BOT_TOKEN` مطلوبًا لتشغيل Telegram.
- يجب تشغيل `telegram_bot.py` كخدمة مستمرة منفصلة؛ وجود الملف في المستودع وحده لا يشغّل البوت.
- لا تحفظ مفاتيح API أو رموز البوت في ملفات GitHub.
- استخدام OpenAI API يُحاسب بشكل منفصل عن اشتراك ChatGPT، حسب الاستهلاك.


## التداول الآلي التجريبي (إصدار أولي)
أضيفت إلى بوت Telegram قائمة **التداول الآلي التجريبي**:
- مدد تشغيل: ساعة، 3، 6، 12، أو 24 ساعة.
- مخاطرة محاكاة: 0.5% أو 1% لكل صفقة.
- حد خسارة يومية قابل للاختيار: 2% أو 3% أو 5%.
- رأس مال افتراضي يحدده المستخدم.
- فحص أصول العملات الرقمية كل 5 دقائق، مع صفقة افتراضية مفتوحة واحدة كحد أقصى لكل مستخدم.
- متابعة وقف الخسارة والهدف وإشعارات فتح/إغلاق الصفقات.
- إغلاق المراكز الافتراضية عند إيقاف الجلسة أو انتهاء مدتها.
- بيانات الجلسات والصفقات تحفظ في SQLite باستخدام BOT_DB_PATH.

### حدود هذا الإصدار
- **محاكاة فقط**: لا يتصل هذا المحرك بحساب تداول، ولا يرسل أوامر شراء أو بيع حقيقية، ولا يحتاج مفاتيح وسيط.
- يعتمد على قواعد ومؤشرات فنية؛ لا يستخدم نموذج تعلم آلي مدرّب لاتخاذ قرار التداول.
- العملات الرقمية فقط في الفحص الآلي الحالي.
- درجة توافق المؤشرات ليست احتمالاً إحصائياً للربح.
- يجب اختبار الكود وتشغيله في بيئة استضافة فعلية، والتأكد من وجود تخزين دائم لملف SQLite قبل الاعتماد على حفظ الجلسات بعد إعادة تشغيل الخدمة.
- لا تنتقل إلى التداول الحقيقي قبل بناء موصل وسيط مستقل، واختباره على حساب تجريبي، والتحقق من تنفيذ الأوامر وحالات الانقطاع والتكرار وحدود الخسارة.
